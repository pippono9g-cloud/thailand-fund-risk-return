Net inflow (above dashed line) Net outflow (below dashed line) Bubble size = |implied flow| (M THB)  ·  Zero-flow line (dashed) = AUM change explained by return alone (above it ≈ net inflow)
Implication — a category above the dashed line is drawing net inflows (new money chasing the theme — momentum / investor conviction); below it is seeing net outflows (redemptions or rotation out) even when returns are positive; sitting on the line means AUM simply tracked performance with flat flows. The farther a bubble sits from the line, the stronger the flow signal — and a category that is both high-return and well above the line is where performance and demand reinforce each other.
Implied flow = AUM change − Weighted return
Methodology
  • Each bubble is an AIMC sub-category.
  • X = AUM-weighted total return of the share classes in the category over the selected window (each class weighted by its AUM at the start of the window; class returns from the weekly SEC build). Only classes with AUM at both window endpoints are included, so X and Y cover the same funds.
  • Y = % change in the category's total AUM over the same window, from SEC NAV history. Only share classes with AUM at both window endpoints are counted, so the change is like-for-like.
  • AUM change ≈ market move + net flows, so the vertical distance from the dashed 45° line ≈ net subscription (above the line) or redemption (below).
  • Implied flow (pp) = AUM change − AUM-weighted return, in percentage points: +5 pp ≈ net inflow of about 5% of the category's assets; −5 pp ≈ net outflow. (It's "pp" not "%" because it's the gap between two percentages.) pp measures intensity relative to size — a small fund can print a hot pp on little actual money.
  • Flow (M THB) = start-of-window AUM × implied flow — the estimated actual money that moved in or out, net of performance. Use this to compare across categories/funds of different sizes; use pp to gauge demand intensity. Funds whose start AUM is below 100M THB carry an ᴸ marker on their pp (low base — read the M THB column instead).
  • Categories with fewer than 3 funds are excluded.
